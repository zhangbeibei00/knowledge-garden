# LLaDA 训练 + 推理流程图

配套 [LLaDA 方法解析](./llada-method.md) 的可视化版本。

## 训练侧

```
┌─────────────────────────────────────────────────────┐
│ Step 1 · 采样原始序列                                │
│   x₀ = [今, 天, 天, 气, 很, 好]                      │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│ Step 2 · 采样掩码强度                                │
│   t ~ Uniform(0, 1)   例如 t = 0.5                  │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│ Step 3 · 独立 mask 每个位置                         │
│   每位置以 t=0.5 概率被替换为 [MASK]                │
│   x_t = [今, [M], 天, [M], 很, [M]]                 │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│ Step 4 · 双向 Transformer 前向                       │
│   无 causal mask · RoPE · SwiGLU · RMSNorm          │
│   logits = model(x_t)   形状 [L, V]                 │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│ Step 5 · Masked CE Loss                             │
│   只在 mask 位置算交叉熵:                            │
│   L = (1/t) · Σ CE(logits_i, x_0^i)                 │
│                          i ∈ mask 位置              │
│   (1/t) 加权 → 变分下界的 principled 上界           │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│ Step 6 · Backward + Optimizer Step                  │
│   AdamW · warmup · gradient clipping                │
└─────────────────────────────────────────────────────┘
```

## 推理侧（N 步迭代）

```
Step 0 · 初始化
   Prompt + Response 区(全 [MASK])
   [介绍扩散模型] + [M M M M M M M M M M]
                        ↓

  ┌─────────────── FOR step = 1..N ────────────────┐
  ↓                                                │
┌─────────────────────────────────────────────────┐│
│ ① 双向 Transformer 前向                          ││
│    对当前 x_t 全序列 self-attention              ││
│    logits = model(x_t)                          ││
└─────────────────────────────────────────────────┘│
                        ↓                          │
┌─────────────────────────────────────────────────┐│
│ ② 预测所有 M 位置 + 置信度                        ││
│    tokens = argmax(logits)                      ││
│    confidence = max(softmax(logits))            ││
│    例: [扩(.9), 散(.85), M, 型(.6), 是(.95)...]  ││
└─────────────────────────────────────────────────┘│
                        ↓                          │
┌─────────────────────────────────────────────────┐│
│ ③ Remask 策略                                    ││
│    保留 top-k 置信度位置,其他 remask             ││
│    • Low-Conf(默认) • Random • Semi-AR(SFT)     ││
│    k = L / N   (均匀分配)                        ││
└─────────────────────────────────────────────────┘│
                        ↓                          │
                    还有 M?  ────── 是 ────────────┘
                        ↓ 否
                    输出完整 Response
                    [扩, 散, 模, 型, 是, 一, 种, ...]
```

## 关键概念对照

| 符号/术语 | 含义 |
|---------|------|
| **x₀** | 原始 token 序列（训练时的 ground truth） |
| **x_t** | 加噪后的序列（部分 token 被替换为 [MASK]） |
| **t** | 掩码强度 ∈ (0, 1)，训练时从 Uniform(0,1) 采样 |
| **[MASK]** | 特殊 token，占位符，作为被"加噪"的替代 |
| **双向 Transformer** | 去掉 causal mask 的标准 Transformer（其他组件与 LLaMA 一致） |
| **(1/t) 加权** | 变分下界推导出的归一化系数，让不同 t 的 loss 贡献均衡 |
| **N 步迭代** | 推理时的采样步数，可调（N=1 极快但差，N=L 慢但好，甜点 L/8） |
| **Low-Conf Remask** | Base 版默认策略：保留高置信度位置，低置信度重新 mask |
| **Semi-AR Remask** | SFT 常用：切成 block，块内并行，块间左到右，支持流式输出 |
